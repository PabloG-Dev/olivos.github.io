1 Introducción a OlivOS

¿Qué es OlivOS?

OlivOS es una distribución Linux de escritorio basada en Void Linux, diseñada para ofrecer una experiencia moderna, optimizada y accesible. Su objetivo principal es combinar las últimas tecnologías del ecosistema Linux con un consumo de recursos responsable, de modo que puedas disfrutar de un escritorio completo y funcional sin sacrificar el rendimiento de tu equipo.

A diferencia de muchas distribuciones que priorizan lo ligero eliminando funcionalidades, OlivOS apuesta por un enfoque equilibrado: incluye herramientas modernas como PipeWire para el audio, Wayland a través de LabWC como compositor gráfico, y tecnologías de optimización como zram, TLP y ananicy, todo ello preconfigurado para que el sistema funcione de forma óptima desde el primer momento.

OlivOS es un proyecto derivado de la experiencia acumulada en CuerdOS Linux, otra distribución mantenida por el mismo desarrollador durante años. Mientras que CuerdOS tiene su propia identidad y trayectoria, OlivOS nace como un port renovado que aprovecha la solidez de Void Linux como base, añadiendo su propio escritorio, herramientas personalizadas y repositorios de paquetes para ofrecer una experiencia coherente y pulida.

¿Por qué Void Linux?

Void Linux es una distribución independiente conocida por su estabilidad, simplicidad y rendimiento. Utiliza xbps como gestor de paquetes —rápido y ligero— y runit como sistema de inicio, que destaca por su velocidad de arranque y su filosofía minimalista. Estas características lo convierten en una base ideal para una distribución de escritorio que busca la eficiencia sin renunciar a la funcionalidad moderna.

Características principales

🎮 Escritorio moderno

LXQt con LabWC (Wayland) ofrece un escritorio ligero y visualmente atractivo con soporte nativo para Wayland, el protocolo gráfico del futuro.

⚡ Rendimiento optimizado

zram, TLP y ananicy trabajan juntos para maximizar el rendimiento de tu hardware, ya sea un equipo potente o uno más modesto.

🔈 Audio moderno

PipeWire con WirePlumber como gestor de sesión proporciona audio y vídeo de baja latencia, compatible con aplicaciones PulseAudio y JACK.

🔧 Herramientas propias

runitctl para gestionar servicios, opkg como gestor de paquetes simplificado, Almazara como instalador gráfico y OlivOS-Welcome para tu primera configuración.

📦 Repositorios propios

OlivOS incluye sus propios repositorios en packages.olivoslinux.com con software seleccionado y optimizado para la distribución.

🐳 Kernel personalizado

El kernel de Linux se compila semanalmente con configuraciones optimizadas para el escritorio OlivOS, ofreciendo las últimas correcciones y mejoras.

2 Requisitos del sistema

OlivOS está diseñado para funcionar de forma eficiente en una amplia gama de hardware. Gracias a las optimizaciones integradas como zram y el escritorio LXQt, el sistema puede ejecutarse en equipos con recursos limitados, aunque la experiencia óptima se obtiene con las especificaciones recomendadas.

Componente Mínimo Recomendado
Procesador Cualquier CPU x86_64 1.5 GHz, 2 núcleos, 2 hilos
Memoria RAM 2 GB 4 GB o más
Disco 50 GB (SSD preferible) 100 GB SSD
Tarjeta gráfica Cualquier GPU con soporte en Linux GPU con drivers libres o NVIDIA
Modo de arranque UEFI y BIOS/Legacy

Consejo sobre zram: OlivOS utiliza zram para comprimir parte de la RAM y usarla como swap. Esto significa que con 2 GB de RAM física, el sistema puede manejar más carga de la que esperarías, ya que zram le da un "respiradero" al sistema. No obstante, para uso intensivo (navegación con muchas pestañas, edición de imágenes, etc.), 4 GB o más hacen una diferencia notable.

Arquitectura soportada

Actualmente OlivOS está disponible para la arquitectura x86_64 (AMD64). Se planea en el futuro aportar soporte para dispositivos ARM, lo que permitirá ejecutar OlivOS en placas como Raspberry Pi u otros dispositivos de esa arquitectura.

3 Creación de medios de instalación

Para instalar OlivOS necesitas crear un medio de arranque (USB o DVD) con la imagen ISO del sistema. Esta imagen se puede descargar desde la página oficial del proyecto y se graba en una memoria USB para arrancar el sistema en modo "live" —es decir, puedes probar OlivOS sin instalarlo— y, cuando estés listo, iniciar el instalador gráfico Almazara.

Descarga de la ISO

La imagen ISO de OlivOS se puede descargar desde la página oficial:

olivoslinux.com

Una vez descargada, verifica que el archivo no esté corrupto. Si la página proporciona sumas de verificación (SHA256), compáralas con la de tu archivo descargado:

sha256sum OlivOS-0.9-x86_64.iso

Crear USB de arranque

En Linux

El método más directo es usar dd, que copia la imagen byte a byte al dispositivo USB. Ten mucho cuidado de indicar el dispositivo correcto, ya que este proceso borra todo el contenido del USB.

# Encuentra tu dispositivo USB (por ejemplo, /dev/sdX)
lsblk

# Graba la ISO en el USB (reemplaza X por la letra correcta)
sudo dd if=OlivOS-0.9-x86_64.iso of=/dev/sdX bs=4M status=progress && sync

También puedes usar herramientas gráficas como USBImager o Ventoy si prefieres una interfaz visual.

En Windows

Puedes usar Rufus o balenaEtcher para crear el USB de arranque de forma sencilla:

  1. Descarga e instala Rufus desde rufus.ie.
  2. Inserta tu memoria USB.
  3. Selecciona la ISO de OlivOS y el dispositivo USB.
  4. Escribe la imagen en modo DD (no ISO) si Rufus te lo pregunta.
  5. Haz clic en "Empezar" y espera a que finalice.

En macOS

# Identifica el dispositivo USB
diskutil list

# Graba la ISO (reemplaza X por el número correcto)
sudo dd if=OlivOS-0.9-x86_64.iso of=/dev/diskX bs=4m

Importante: El proceso dd borra todo el contenido del USB. Asegúrate de que el dispositivo indicado es correcto antes de ejecutar el comando. Un error puede sobrescribir datos de tu disco duro.

4 Instalación de OlivOS

OlivOS utiliza Almazara Installer, un instalador gráfico desarrollado en Python con PySide6 (Qt6) que te guiará paso a paso por todo el proceso de instalación. Su interfaz está diseñada para ser intuitiva, incluso si nunca has instalado un sistema Linux antes.

Arrancar desde el USB

  1. Inserta el USB de arranque en el equipo donde quieres instalar OlivOS.
  2. Enciende (o reinicia) el equipo y accede a la BIOS/UEFI para seleccionar el USB como dispositivo de arranque. Normalmente se accede pulsando F2, F12, Esc o Del durante el arranque (depende del fabricante).
  3. Selecciona "OlivOS" en el menú de arranque. El sistema se cargará en modo "live".

Sesión live

Al arrancar en modo live, OlivOS se ejecuta íntegramente desde el USB sin tocar tu disco duro. Esto te permite explorar el escritorio, probar que tu hardware funciona correctamente y, cuando estés listo, lanzar el instalador desde la aplicación OlivOS-Welcome que aparece al inicio. Simplemente haz clic en el botón "Instalar OlivOS".

Pasos del instalador Almazara

Almazara te guiará a través de seis páginas consecutivas. A continuación se describe cada una de ellas en el orden en que aparecen:

Página 1 — Inicio

La primera página del instalador te permite seleccionar el idioma de la interfaz del propio instalador. Además, Almazara detecta automáticamente si tu equipo tiene conexión a internet. Esta detección es importante porque, si estás online, el instalador podrá sincronizar los repositorios de paquetes más recientes y ofrecerte las últimas versiones disponibles. Si estás offline, la instalación se realizará con los paquetes incluidos en la ISO.

Página 2 — Zona horaria, locales y teclado

En esta página configurarás los ajustes regionales básicos del sistema:

  • Zona horaria: Selecciona tu ubicación geográfica para que el sistema muestre la hora correcta.
  • Locale (idioma del sistema): Define el idioma y los formatos regionales (fecha, números, etc.) que usará el sistema.
  • Distribución del teclado: Elige el mapa de teclado correspondiente a tu teclado físico (es, en, latam, etc.).

Página 3 — Repositorios y controladores

Esta página solo aparece cuando el instalador se ejecuta en modo online. Si seleccionaste modo offline en la primera página, esta página se omite y la instalación se realiza con los paquetes incluidos en la ISO. En modo online, puedes configurar los orígenes de software y los controladores adicionales:

  • Repositorios (mirrors): Selecciona los servidores de paquetes más rápidos para tu ubicación. OlivOS utiliza los repositorios oficiales de Void Linux más su propio repositorio en packages.olivoslinux.com.
  • Repositorios non-free: Puedes habilitar los repositorios de software privativo, necesarios para ciertos controladores y firmware.
  • Drivers NVIDIA: Si tu equipo tiene una tarjeta gráfica NVIDIA, puedes instalar los drivers propietarios directamente desde aquí. Si tu GPU es AMD o Intel, no necesitas esta opción, ya que los drivers libres funcionan de serie.
  • Microcódigo Intel: Actualizaciones de microcódigo para procesadores Intel que corrigen errores y vulnerabilidades a nivel de hardware.

Página 4 — Usuario y hostname

En esta página configurarás la identidad de tu equipo y tu cuenta de usuario:

  • Hostname: El nombre que identificará a tu equipo en la red local (por ejemplo, "olivos-pc").
  • Nombre completo: Tu nombre real, que se mostrará en la pantalla de inicio de sesión y en otras partes del sistema.
  • Nombre de usuario: El identificador de tu cuenta (sin espacios ni caracteres especiales).
  • Contraseña: La contraseña para tu cuenta de usuario y la contraseña de root (administrador), ambas obligatorias.

Página 5 — Discos y particionado

Esta es la página más importante del instalador. Aquí seleccionarás el disco donde instalar OlivOS y cómo se particionará:

  • Particionado automático: Almazara ejecutará un script (auto_partition.sh) que creará automáticamente un esquema de partición básico en el disco seleccionado (raíz, EFI, swap). Es la opción más rápida si quieres instalar OlivOS en un disco entero.
  • Particionado manual: Puedes abrir KDE Partition Manager directamente desde el instalador para crear, redimensionar o eliminar particiones a tu gusto. Esto es útil si quieres conservar otros sistemas operativos o tener un esquema personalizado.

Después de particionar (ya sea automática o manualmente), debes indicar qué función cumple cada partición usando los menús desplegables del instalador: EFI, raíz (/), /home o swap. Los sistemas de archivos soportados son ext4/3/2, btrfs y xfs para raíz y home; FAT/VFAT para EFI.

Instalación junto a otro sistema: Almazara no ofrece una opción automática para instalar OlivOS junto a otro sistema operativo, pero es posible hacerlo particionando manualmente con KDE Partition Manager y seleccionando las particiones correspondientes en el instalador. Asegúrate de dejar espacio libre sin asignar antes de iniciar.

Página 6 — Instalación en progreso

Una vez revisada toda la configuración, haz clic en "Instalar". Almazara comenzará el proceso de copia del sistema al disco. El instalador muestra una barra de progreso animada y, opcionalmente, un terminal de registro en tiempo real para que puedas seguir el avance de la instalación. La interfaz permanece siempre respondiendo gracias a que el proceso se ejecuta en un hilo separado. Las tareas que se realizan automáticamente son:

  1. Copiar el sistema base al disco.
  2. Generar el archivo fstab con las particiones configuradas.
  3. Crear el usuario y configurar las contraseñas.
  4. Establecer el idioma, zona horaria y teclado.
  5. Regenerar el initramfs (imagen de arranque del kernel).
  6. Instalar el gestor de arranque GRUB.

Sobre el cifrado: Almazara no ofrece cifrado de disco (LUKS) de forma automática. Si necesitas cifrar tu disco, deberás preparar las particiones cifradas manualmente antes de ejecutar el instalador y luego seleccionarlas en el paso de particionado.

Tu primer inicio

La primera vez que entres, se abrirá automáticamente la aplicación OlivOS-Welcome, que te da acceso rápido a varias funciones útiles para configurar tu sistema recién instalado.

OlivOS-Welcome

La pantalla de bienvenida ofrece las siguientes opciones:

🌐 Página oficial

🛒 Tienda de aplicaciones

El escritorio LXQt + LabWC

OlivOS utiliza LXQt como entorno de escritorio, combinado con LabWC como compositor Wayland. LXQt es un escritorio ligero y rápido que no consume muchos recursos, mientras que LabWC aporta las capacidades gráficas modernas de Wayland: composición fluida, mejor gestión de ventanas y preparación para el futuro del escritorio Linux.

El tema visual de OlivOS es propio, con una paleta de colores verdes orgánicos y agradables inspirados en la naturaleza del olivo, y un estilo similar a Breeze (el tema de KDE). El resultado es un escritorio coherente, moderno y con personalidad propia.

6 Conexión a internet

Para actualizar el sistema e instalar software, necesitas conectarte a internet. OlivOS incluye herramientas para conectarte tanto por cable como por Wi-Fi.

Conexión por cable (Ethernet)

Si usas un cable de red, la conexión suele ser automática gracias al servicio dhcpcd. Simplemente conecta el cable y comprueba que tienes acceso a internet:

ping -c 3 olivoslinux.com

Si no funciona automáticamente, asegúrate de que el servicio dhcpcd está habilitado y activo:

# Habilitar dhcpcd si no lo está
sudo runitctl enable dhcpcd
sudo runitctl start dhcpcd

Conexión Wi-Fi

Para conectarte a una red Wi-Fi desde el escritorio, puedes usar el applet de red de LXQt en la bandeja del sistema. Si prefieres la terminal:

# Listar redes disponibles
sudo iwctl station wlan0 scan
sudo iwctl station wlan0 get-networks

# Conectarse a una red
sudo iwctl station wlan0 connect "NombreDeTuRed"

# Si necesitas usar wpa_supplicant directamente
sudo wpa_supplicant -B -i wlan0 -c <(wpa_passphrase "NombreDeTuRed" "TuContraseña")
sudo dhcpcd wlan0

Consejo: Para que la conexión Wi-Fi se conecte automáticamente al arrancar, asegúrate de habilitar el servicio correspondiente con runitctl enable <servicio>. Puedes usar runitctl list-all para ver los servicios de red disponibles.

7 Actualización del sistema

Mantener tu sistema actualizado es importante para recibir las últimas correcciones de seguridad, mejoras de rendimiento y nuevas versiones de software. OlivOS hereda el sistema de paquetes de Void Linux, que permite actualizaciones rápidas y seguras.

Actualizar los paquetes

Para actualizar todo el sistema, ejecuta estos dos comandos:

# Sincronizar los repositorios (descargar la lista de paquetes más reciente)
sudo xbps-install -S

# Actualizar todos los paquetes instalados
sudo xbps-install -u

Puedes combinar ambos comandos en uno solo:

sudo xbps-install -Su

Actualizar el kernel

Cuando se actualiza el kernel de OlivOS (recuerda que se compila semanalmente), necesitas regenerar la imagen de arranque para que los cambios surtan efecto:

# Después de actualizar, reconfigura el kernel
sudo xbps-reconfigure -f linux

Si tienes instalados múltiples versiones del kernel, puedes verificar cuál está activa:

uname -r

Actualización desde la interfaz gráfica

Si prefieres no usar la terminal, puedes actualizar el sistema desde OctoXBPS (el gestor gráfico de paquetes). Abre OctoXBPS, haz clic en "Actualizar" y confirma los cambios. También puedes usar el botón "Actualizar sistema" en OlivOS-Welcome.

Sobre los repositorios: OlivOS utiliza los repositorios oficiales de Void Linux más su propio repositorio en packages.olivoslinux.com. Al ejecutar xbps-install -S, se sincronizan ambos orígenes. Los paquetes propios de OlivOS (como el instalador, runitctl o el tema visual) provienen del repositorio de OlivOS.

Instantáneas del sistema con Timeshift

Antes de realizar una actualización importante, es buena idea crear un punto de restauración. OlivOS incluye Timeshift, una herramienta que crea instantáneas del sistema que puedes restaurar si algo sale mal. Puedes acceder a él desde OlivOS-Welcome o desde el menú de aplicaciones.

# Crear una instantánea manual desde la terminal
sudo timeshift --create --comments "Antes de actualización importante"

8 Gestión de paquetes: xbps, opkg y OctoXBPS

El gestor de paquetes xbps

xbps (X Binary Package System) es el gestor de paquetes nativo de Void Linux y, por tanto, la base sobre la que OlivOS gestiona el software. Trabaja con paquetes binarios precompilados, lo que hace que la instalación sea rápida. A continuación se muestra una tabla de referencia rápida con los comandos más utilizados:

Acción Comando

opkg — Gestor de paquetes simplificado

¿Qué es opkg?

opkg es un wrapper (envoltorio) alrededor de xbps escrito en Bash que ofrece una sintaxis similar a apt, el gestor de paquetes de Debian y Ubuntu. Su propósito es hacer más intuitiva la gestión de paquetes en OlivOS, especialmente para usuarios que provienen de distribuciones basadas en Debian y que no están familiarizados con los comandos de xbps. Cuando ejecutas un comando opkg, este traduce la acción al comando xbps correspondiente y lo ejecuta en segundo plano, añadiendo además salida coloreada y una barra de progreso visual para las descargas.

opkg es software libre licenciado bajo GPLv3 y su código fuente está disponible en github.com/PabloG-Dev/OPKG.

Sintaxis general

opkg <acción> [paquete...]

Si ejecutas opkg sin argumentos, se mostrará un mensaje de uso básico. Para ver la ayuda completa, usa opkg --help.

Comandos disponibles

La siguiente tabla muestra todos los comandos de opkg, su equivalente en xbps y una descripción:

Ejemplos prácticos

Instalar un paquete

# Actualizar repositorios e instalar un paquete
sudo opkg update
sudo opkg install gimp

# Instalar varios paquetes a la vez
sudo opkg install gimp inkscape blender

Actualizar el sistema completo

# Sincronizar y actualizar todos los paquetes
sudo opkg update
sudo opkg upgrade

Si el sistema ya está actualizado, opkg mostrará un mensaje en amarillo indicando que no hay actualizaciones disponibles, en lugar de mostrar un error.

Eliminar paquetes y limpiar

# Eliminar un paquete (sin sus dependencias)
sudo opkg remove gimp

# Eliminar un paquete junto con sus dependencias
sudo opkg purge gimp

# Eliminar dependencias huérfanas que ya no necesita nadie
sudo opkg autoremove

# Limpiar caché de paquetes descargados y huérfanos
sudo opkg clean

Buscar paquetes

# Buscar un paquete en los repositorios
opkg search firefox

# Ver información de un paquete (funciona tanto si está instalado como si está en el repositorio)
opkg info firefox

Cuando buscas con opkg search, el término de búsqueda se resalta en amarillo dentro de los resultados, lo que facilita identificar rápidamente las coincidencias. Los nombres de paquetes aparecen en verde.

Consultas sobre paquetes

# Averiguar qué paquete posee un archivo
opkg which /usr/bin/firefox

# Ver las dependencias de un paquete
opkg depends firefox

# Ver qué paquetes dependen de este
opkg reverse-deps firefox

# Listar los archivos que instaló un paquete
opkg files firefox

Privilegios de root

Los comandos que modifican el sistema (install, remove, purge, update, upgrade, autoremove, clean) requieren privilegios de administrador. Si ejecutas uno de estos comandos sin sudo, opkg detectará que no tienes permisos y te sugerirá el comando correcto con sudo, mostrando la acción y los argumentos en verde. Los comandos de consulta (search, list, info, files, which, depends, reverse-deps, repos) no necesitan sudo y puedes ejecutarlos como usuario normal.

Diferencia importante: remove vs purge

Un par de comandos de opkg puede generar confusión si vienes de apt:

  • opkg remove vs opkg purge: remove elimina solo el paquete indicado, dejando sus dependencias instaladas. purge elimina el paquete y recursivamente todas sus dependencias que ya no sean necesarias. En apt, purge elimina los archivos de configuración; en opkg, la diferencia es la eliminación recursiva de dependencias.

OctoXBPS — Gestión gráfica de paquetes

OlivOS incluye OctoXBPS, un gestor gráfico de paquetes muy potente que actúa como frontend visual de xbps. Con OctoXBPS puedes realizar todas las operaciones de gestión de paquetes directamente desde la interfaz gráfica: buscar paquetes disponibles en los repositorios, instalar nuevos programas, actualizar los ya instalados y eliminar los que ya no necesites, todo con unos pocos clics y sin necesidad de recordar comandos. La interfaz muestra información detallada de cada paquete (versión, descripción, dependencias, tamaño) y te permite filtrar y ordenar los resultados para encontrar rápidamente lo que buscas. Lo encontrarás en el menú de aplicaciones bajo la categoría «Sistema». Es la opción ideal si prefieres no usar la terminal para gestionar el software de tu equipo.

Software que no está en los repositorios: Si un programa no está disponible en los repositorios de Void Linux ni en los de OlivOS, puedes buscarlo en Flathub (usando Flatpak), descargarlo como AppImage o, en algunos casos, usar contenedores Distrobox. OlivOS también planea ampliar su repositorio propio con el tiempo.

9 Gestión de servicios con runitctl

En la mayoría de distribuciones Linux, los servicios se gestionan con systemctl (parte de systemd). Sin embargo, Void Linux y OlivOS utilizan runit como sistema de inicio, que tiene una forma diferente de gestionar servicios. Para facilitar la transición, OlivOS incluye runitctl, un script que ofrece una interfaz similar a systemctl para gestionar servicios runit de forma sencilla e intuitiva.

¿Qué es un servicio?

Un servicio (o demonio, "daemon") es un programa que se ejecuta en segundo plano y proporciona una función esencial del sistema. Ejemplos de servicios son el gestor de red, el servidor de audio, el gestor de inicio de sesión, etc. En runit, los servicios se encuentran en dos ubicaciones clave:

  • /etc/sv/ — Contiene las definiciones de todos los servicios disponibles en el sistema.
  • /var/service/ — Contiene enlaces simbólicos a los servicios que están habilitados (se iniciarán automáticamente).

Cuando un servicio está "habilitado", significa que runit lo iniciará automáticamente al arrancar el sistema. Cuando está "deshabilitado", el servicio existe pero no arranca solo, aunque puedes iniciarlo manualmente.

Comandos de runitctl

Comando Descripción
runitctl start servicioIniciar un servicio
runitctl stop servicioDetener un servicio
runitctl restart servicioReiniciar un servicio
runitctl status servicioMostrar el estado de un servicio
runitctl enable servicioHabilitar un servicio (inicio automático)
runitctl disable servicioDeshabilitar un servicio
runitctl list-activeListar servicios activos
runitctl list-allListar todos los servicios disponibles
runitctl --helpMostrar ayuda

Ejemplos prácticos

Habilitar e iniciar el servicio de red

# Habilitar dhcpcd para conexión automática por cable
sudo runitctl enable dhcpcd
sudo runitctl start dhcpcd

# Verificar que funciona
runitctl status dhcpcd

Reiniciar el servicio de audio

sudo runitctl restart pipewire

Ver qué servicios están activos

runitctl list-active

Esto mostrará una lista con un indicador verde al lado de cada servicio que se esté ejecutando. Para ver también los servicios disponibles pero deshabilitados:

runitctl list-all

Los servicios habilitados aparecerán con un indicador verde y los deshabilitados con un indicador rojo.

Nota: runitctl requiere privilegios de administrador (sudo) para la mayoría de operaciones. Si intentas ejecutar una acción sin sudo, el propio runitctl te sugerirá que uses sudo runitctl.

10 Audio, gráficos y controladores

Audio con PipeWire

OlivOS utiliza PipeWire como servidor de audio, junto con WirePlumber como gestor de sesión. PipeWire es la tecnología de audio moderna en Linux, diseñada para sustituir tanto a PulseAudio como a JACK, ofreciendo baja latencia y compatibilidad con ambos ecosistemas. En la práctica, esto significa que tus aplicaciones de audio y vídeo funcionarán correctamente sin necesidad de configuración adicional.

Si necesitas ajustar el volumen o seleccionar dispositivos de entrada/salida, puedes usar pavucontrol (Control de volumen de PulseAudio), que es compatible con PipeWire a través de su capa de compatibilidad PulseAudio. Si no está instalado:

sudo xbps-install pavucontrol

Problemas comunes de audio

  • No hay sonido: Verifica que PipeWire se está ejecutando con runitctl status pipewire y que los dispositivos de salida no están silenciados en pavucontrol.
  • Audio cortado o con chasquidos: Comprueba que el servicio de PipeWire está activo y que no hay conflictos con PulseAudio (que no debería estar instalado si usas PipeWire).
  • El micrófono no funciona: Abre pavucontrol, ve a la pestaña "Configuración" y asegúrate de que el perfil del dispositivo de entrada incluye "Entrada estéreo" o similar.

Controladores gráficos

AMD

Las tarjetas gráficas AMD funcionan de serie en OlivOS con los drivers libres amdgpu, incluidos en el kernel. No necesitas instalar nada adicional. El soporte incluye aceleración por hardware de vídeo, salida a monitores externos y composición Wayland.

Intel

Las GPU Intel integradas también funcionan con los drivers libres (i915) incluidos en el kernel. Se recomienda instalar el microcódigo de Intel (puedes hacerlo durante la instalación con Almazara o después):

sudo xbps-install intel-ucode
sudo xbps-reconfigure -f linux

NVIDIA

Si tu equipo tiene una GPU NVIDIA, tienes dos opciones:

  • Drivers propietarios (recomendado para rendimiento): Puedes instalarlos durante la instalación con Almazara o después: 
    # Instalar drivers NVIDIA
sudo xbps-install nvidia

# Regenerar initramfs
sudo xbps-reconfigure -f linux
  • Driver libre Nouveau: Viene por defecto con el kernel. Funciona para uso básico, pero no ofrece el mismo rendimiento que los drivers propietarios, especialmente para tareas 3D o gaming.

Wayland con LabWC

OlivOS utiliza LabWC como compositor Wayland para el escritorio LXQt. Wayland es el protocolo gráfico moderno que sustituye a X11, ofreciendo mejor composición, seguridad y fluidez. LabWC es un compositor ligero compatible con el estándar wlroots, diseñado para ser rápido y sencillo.

Para configurar tus monitores y pantallas, OlivOS incluye wdisplays, una herramienta gráfica que te permite organizar la disposición de las pantallas, ajustar resoluciones y tasas de refresco. La encontrarás en el menú de aplicaciones.

Kernel personalizado: El kernel de OlivOS se compila semanalmente con configuraciones optimizadas. Esto significa que los módulos de drivers más comunes están incluidos, pero si tienes hardware muy específico, puede que necesites cargar módulos adicionales manualmente.

11 Solución de problemas

Esta sección recoge los problemas más comunes que puedes encontrar al usar OlivOS y sus soluciones. Si tu problema no está aquí, consulta la sección de preguntas frecuentes o visita la wiki oficial en olivoslinux.com.

El sistema no arranca

Si tras la instalación OlivOS no arranca, puede deberse a varias causas:

  • GRUB no se instaló correctamente: Arranca desde el USB live, abre una terminal y reinstala GRUB: 
    # Montar la partición raíz (ajusta sdXn a tu partición)
sudo mount /dev/sdXn /mnt

# Si tienes EFI, monta también la partición EFI
sudo mount /dev/sdXm /mnt/boot/efi

# Reinstalar GRUB
sudo chroot /mnt grub-install /dev/sdX   # Para BIOS
sudo chroot /mnt grub-install --target=x86_64-efi --efi-directory=/boot/efi  # Para UEFI
sudo chroot /mnt update-grub
  • Partición EFI no seleccionada: En sistemas UEFI, asegúrate de que la partición EFI está correctamente formateada como FAT32 y montada en /boot/efi.
  • Orden de arranque en la BIOS: Entra en la BIOS/UEFI y verifica que OlivOS aparece en el orden de arranque. Si no, añade la entrada manualmente.

Problemas de Wi-Fi

  • No se detecta la tarjeta Wi-Fi: Verifica si tu tarjeta requiere firmware privativo. Ejecuta sudo xbps-install linux-firmware y reinicia.
  • La conexión se cae constantemente: Prueba a desactivar la gestión de energía de la tarjeta con sudo iwconfig wlan0 power off.
  • No puedo conectarme con iwctl: Asegúrate de que el servicio iwd está habilitado: sudo runitctl enable iwd && sudo runitctl start iwd.

Problemas con NVIDIA

  • Pantalla negra después de instalar drivers NVIDIA: Esto puede deberse a un conflicto con el driver Nouveau. Añade rd.driver.blacklist=nouveau a los parámetros del kernel en /etc/default/grub y ejecuta sudo update-grub.
  • Wayland no funciona con NVIDIA: Los drivers NVIDIA propietarios tienen soporte limitado para Wayland. Asegúrate de usar la versión más reciente del driver y de que tienes habilitados los mods de kernel necesarios: nvidia-drm.modeset=1.
  • Rendimiento pobre en juegos: Verifica que la aceleración 3D está activa con glxinfo | grep "OpenGL renderer". Si muestra "llvmpipe", los drivers no están cargando correctamente.

Problemas de audio

  • No hay sonido: Ejecuta runitctl status pipewire para verificar que PipeWire está activo. Si no, inícialo con runitctl start pipewire.
  • Solo se escucha por un canal: Abre pavucontrol y verifica la configuración del perfil del dispositivo en la pestaña "Configuración".
  • El audio se corta: Puede ser un problema de prioridad del proceso. Instala y configura rtkit para que PipeWire tenga prioridad en tiempo real: sudo xbps-install rtkit.

Problemas con paquetes

  • Error "unable to locate package": Primero sincroniza los repositorios: sudo xbps-install -S.
  • Error "conflicting package": Usa sudo xbps-install -f paquete para forzar la reinstalación.
  • Paquetes rotos tras una actualización: Ejecuta sudo xbps-reconfigure -fa para reconfigurar todos los paquetes. Si el problema persiste, puedes restaurar una instantánea de Timeshift.

Problemas con Wayland/LabWC

  • Las aplicaciones no se ven correctamente: Algunas aplicaciones antiguas requieren XWayland (una capa de compatibilidad). Asegúrate de que está instalado: sudo xbps-install xorg-server-xwayland.
  • No puedo compartir pantalla en videollamadas: Verifica que PipeWire y xdg-desktop-portal están instalados y ejecutándose: sudo xbps-install xdg-desktop-portal xdg-desktop-portal-wlr.

13 Preguntas frecuentes

¿En qué se diferencia OlivOS de Void Linux?

OlivOS está basado en Void Linux, pero añade varias capas encima: un escritorio preconfigurado (LXQt + LabWC con Wayland), herramientas propias como runitctl, opkg y el instalador Almazara, optimizaciones preconfiguradas (zram, TLP, ananicy), un tema visual propio, un repositorio de paquetes adicional, y un kernel compilado semanalmente. Mientras que Void Linux es una base excelente pero requiere configuración manual, OlivOS ofrece una experiencia lista para usar desde la instalación, reduciendo significativamente la curva de aprendizaje.

¿Puedo usar OlivOS si nunca he usado Linux?

Sí. OlivOS está diseñado para ser accesible. El instalador gráfico Almazara te guiará paso a paso, la pantalla de bienvenida te da acceso rápido a las herramientas esenciales, y el gestor gráfico de paquetes OctoXBPS permite instalar software sin tocar la terminal. Dicho esto, algún conocimiento básico de terminal te ayudará a sacar más partido al sistema, especialmente para tareas de configuración o solución de problemas.

¿OlivOS usa systemd?

No. OlivOS utiliza runit como sistema de inicio, igual que Void Linux. runit es más ligero y rápido que systemd, pero funciona de forma diferente. Para facilitar la gestión de servicios, OlivOS incluye runitctl, que ofrece comandos similares a systemctl (start, stop, enable, disable, status), haciendo la transición más sencilla para usuarios acostumbrados a systemd.

¿Cómo instalo software que no está en los repositorios?

Tienes varias opciones: Flatpak (con el repositorio Flathub, que contiene miles de aplicaciones), AppImage (aplicaciones autocontenidas que solo necesitas descargar y ejecutar), Distrobox (para ejecutar aplicaciones de otras distribuciones en contenedores), o compilar desde el código fuente. Con el tiempo, el repositorio de OlivOS también irá ampliándose con más software.

¿OlivOS es estable? ¿Es apto para producción?

OlivOS se encuentra actualmente en versión 0.9 Alpha. Esto significa que, aunque es funcional y usable en el día a día, pueden existir errores o comportamientos inesperados. Para uso crítico o en entornos de producción, se recomienda esperar a versiones más maduras. Sin embargo, la base (Void Linux) es extremadamente estable, y las herramientas propias están en desarrollo activo.

¿Qué es zram y por qué mi swap muestra memoria comprimida?

zram es una tecnología que crea un espacio de swap comprimido directamente en la RAM. En OlivOS, zram está configurado al 25% de tu RAM total mediante zramen. Esto significa que, si tienes 4 GB de RAM, aproximadamente 1 GB se usará como swap comprimida, lo que equivale a más de 1 GB de swap efectivo gracias a la compresión. No te preocupes: esto no "roba" RAM, sino que la usa de forma inteligente cuando el sistema necesita más memoria de la disponible.

¿Puedo instalar OlivOS junto a Windows u otro Linux?

Sí, pero no hay una opción automática en el instalador. Necesitas particionar manualmente el disco usando KDE Partition Manager (disponible desde Almazara), dejando espacio libre para OlivOS, y luego seleccionar las particiones en el instalador. Después de la instalación, GRUB debería detectar automáticamente otros sistemas operativos. Si no lo hace, ejecuta sudo update-grub.

¿Cómo vuelvo a una versión anterior si una actualización falla?

Si tienes una instantánea de Timeshift, puedes restaurarla fácilmente. Si no tienes Timeshift configurado, xbps no tiene un mecanismo nativo de rollback, pero puedes forzar la instalación de una versión específica de un paquete con sudo xbps-install -f paquete=versión. Se recomienda encarecidamente configurar Timeshift para crear instantáneas automáticas antes de actualizaciones importantes.

¿Dónde puedo conseguir ayuda?

Puedes visitar la página oficial olivoslinux.com y la wiki del proyecto. Dado que OlivOS está basado en Void Linux, mucha de la documentación de Void también aplica: docs.voidlinux.org. Para la comunidad de Void, el foro y el canal IRC/Matrix son recursos valiosos.

¿OlivOS es lo mismo que CuerdOS?

No. CuerdOS Linux (cuerdos.github.io) es otra distribución del mismo desarrollador con su propia trayectoria e identidad. OlivOS nace como un port renovado que toma la experiencia de CuerdOS pero sobre una base diferente (Void Linux) y con su propio enfoque, herramientas y comunidad. Son proyectos hermanos, pero independientes.

¿Por qué los paquetes no configuran nada automáticamente?

Esta es una diferencia filosófica importante respecto a distribuciones como Ubuntu o Fedora. En Void Linux (y por extensión en OlivOS), los paquetes instalan los archivos necesarios, pero no ejecutan scripts de post-instalación que modifiquen la configuración del sistema automáticamente. Esto da al usuario control total sobre su sistema, pero requiere que algunos pasos se hagan manualmente (como habilitar servicios con runitctl o regenerar el initramfs). Esta filosofía prioriza la transparencia y el control del usuario sobre la comodidad automática.
